Graphite

DISCLAIMER: For all of these examples we will assume that the standard io libary is used. Import it via use {"stdlib/stdio"}

1. Basics

In graphite variables are declared via the var keyword. Ex: var x = 3; if you want to make the variables type non changeable. Use the strict keyword. Ex: strict var y = "hello"; y = 3 will give an error because 3 and "hello" are not of the same type. if you want to make a variable global. use the global keyword. if(1==1){global strict var x = 0;} Terminal.IO.println(x); will work because the global keyword was used. There are 4 main data types: Int,String,Double,Bool. If you want to free up variables for some reason, use the free(varname). You can use the const keyword to create a constant. The global and strict keyword can also be used before const.

2. Input/Output

To output text into the terminal, first import the stdio library by doing use{ "stdlib/stdio.gr"} after that you can do std.print("Hello World!"). To take in input use the std.input() function. Ex: var a = input();. To clear the terminal use std.clear(). NOTE: Terminal.IO.print, Terminal.IO.println, Terminal.clear() and Terminal.IO.input() is deprecated!!

3. Functions

To create a function use the fn keyword. Ex: fn test(){ return 1+1; } Graphite supports recursion. So you can call functions from inside. Use the global keyword before var if creating a variable in a function,if,else,while and you want it to be accesible from outside.

4. If Else

To create a if statement, use the if keyword followed by the condition inside parantheses. Ex: if(x==y){std.print("x is equal to y.")} The else keyword can only be used after a if statement. The statements inside else only happen if the condition of the if statement is false. Ex: if(2==1){std.print("Correct")}else{std.print("False")}

5. Operators

Comparison operators: is,==,<,>,<=,>=,!= (is and == have the same meaning). Logical operators: ||,&&,and,or (||=or,&&=and). Unary operators: !,-,+ (in some conditions the - and + are unary). Binary Operators: +,-,*,/,^ .

6. Casting

You can cast to int using Int(varname). You can cast to a double value using Double(varname). If you want to cast to a string, just do this. var x = 3; x = ""+3;

7. Syntax

You can either use semicolons or to seperate commands or you can just write it in the next line. Every block of code generates a new scope, but just curly parantheses {} wont generate a new scope.

8. Comments

You can make command using //. Ex: //this is a command!. Note: Multiline comments haven't been implemented yet but will be implemented.

9. Parameters

The parameters type must be defined explicitly (or you can define them without the type but defining with a type is recomended.). Ex: fn test(string name){std.print(name);} test("John");

10. Function usage

User defined functions can be used inside functions. Ex: fn add(int a,int b){return a+b;} Terminal.IO.println(add(3,2));

11. Spaces

Spaces are used to organize values together. ex: space Math{ fn add(double a,double b){return a+b} } Math.add(2,3);

12. Imports

You can import files from another folders relative to the current path using use. Ex: use { "stdlib/math.gh" "stdlib/stdio.gh" "custom.gh"}. You can only write use once per file and you must write it at the top.

13. The standard library

You can use the stdlib/math.gh for functions related to math. You can use the stdlib/stdio.gr for basic IO

stdmath.gr

Functions: max(x,y) , min(x,y) ln(x) for natural log, sin(x),cos(x),tan(x),radToDeg(x),degToRad(y),pi() to get pi,e() to get eulers number. floor(x), ceil(x), round (x), sqrt(x), cbrt(x),root(x,n), pow(x,y) (you can also use the ^ operator. Ex: 3^2) , abs(x)

stdio.gr

Functions: print(val), println(val), input() , clear()

return
}

if(num2 is "-q"){
return
}
Double(num1)
Double(num2)

Terminal.IO.println(num1,operator,num2,"=",num1+num2)

Terminal.IO.println(num1,operator,num2,"=",num1/num2)

Terminal.IO.println(num1,operator,num2,"=",num1*num2)
}
}


Fibonacci Sequence Calculator

fn fib(int n)
{
if(n <= 1)
{
return n;
}
return fib(n - 1) + fib(n - 2);
}
Terminal.IO.println(fib(25));

Delta V Calculator

fn ln(double x)
{
if(x <= 0)
{
return 0;
}
var k = 0;
while(x > e)
{
x = x / e;
k = k + 1;
}

while(x < 1)
{
x = x * e;
k = k - 1;
}

var y = (x - 1) / (x + 1);
var y2 = y * y;
var result = 0.0;
var term = y;
var n = 1;
while(n < 100)
{ result = result + term / n;
term = term * y2;
n = n + 2;
}
return 2 * result + k;
}
fn deltaV(double isp, double initialMass, double finalMass)
{ const g0 = 9.80665;
return isp * g0 * ln(initialMass / finalMass);
}
Terminal.IO.println(deltaV(180,35,20))
